## 2026-10-09：可点击原题链接（0.2.4）

根因：页签接入了鼠标事件，但题面 Markdown 链接只做了显示，没有对应的点击动作。点击回归先复现未处理事件，再验证修复。

- 题面底部原题链接独立渲染并注册可见点击区域，按中文单元宽度、分栏、滚动位置和换行后的 URL 行计算，不依赖固定屏幕行号。
- 左键按下捕获事件，释放后的 click 才执行一次动作，避免一次点击启动两次浏览器；双击的第二次 click 忽略。
- 点击或 F7 先保存草稿，使用题目 slug 构造中国站链接，再调用已有系统浏览器入口。返回后保留焦点与阅读/编辑位置；失败显示可复制的 URL。
- 原题 Markdown 文件保持不变；阅读视图避免重复展示已有原题链接。只对平台原题入口增加点击，不把题面中的任意文本当成可执行链接。

真实 Pi 1.1.0 工具终端：SGR 鼠标按下/释放贯通至 `open` 调用，URL 为当前 Two Sum 原题，随后回到工作台。此验收使用浏览器调用记录桩，没有启动用户浏览器、读取账户或发送判题请求。自动回归同时覆盖成功/失败恢复、草稿保存、滚动/缩放/分栏、换行链接与单次触发。

## 2026-10-09：独立验证反馈修复（精炼候选）

独立验证 `01a11fd5-6cc2-73aa-be27-f56df8f8fe68` 拒绝 5 个 Criterion，对应三处根因。验收标准不变，仅修复实现并补充回归测试。

- **精确题号跨页重复**：改为先解析精确题号并把它从每一页的目录结果中移除，再统一作为逻辑列表的第一项参与分页；这样精确项只出现一次，后续页既不重复也不跳过。
- **仅免费误报无结果**：单次扫描预算从 25 提高到 50 个原始页，且目录提供可跨调用延续的 `items()`；只有源数据真正耗尽才显示“未找到匹配的题目”，仍未耗尽时显示“尚未找到/更多结果可继续加载”并提供 `[继续加载]`（Enter 也可继续）。
- **旧结果可被打开**：`open()` 在搜索 pending 或意图已变化时拒绝打开，并在信息栏提示“正在搜索，结果确认后再打开”；`[打开所选]` 同时置灰。打开只作用于与当前关键词和筛选对应的已确认结果。

新增回归测试覆盖：精确题号在第 2 页不再重复、500 条会员后仍能自动找到免费题、1200 条会员时显示继续加载而非无结果、以及 pending 时无法打开旧列表。以前一版独立验证的同一探针复测：`duplicateAcrossPages:false`、`staleOpen.opened:[]`、`freeScan:{calls:26,items:1,exhausted:true}`。

### 二次精炼：失败路径的旧列表

第二次独立验证（`01a11fe8-4dc0-70a6-9953-8769eb14bd5f`）拒绝 `…7b17` 与 `…7c2a`：新查询失败后 `pendingKey` 被清空，旧列表重新变为可打开，而关键词已经变化。现在改用 `confirmed()`（显示列表的查询键是否等于当前关键词与筛选）判定：查询失败后旧列表仍可读、可重试，但 `open()` 与 `[打开所选]` 均拒绝，并显示“显示上一次结果”；只有重试成功或修改条件后才恢复打开。新增失败路径回归测试，用验证者同一探针复测 `opened` 由 `["1"]` 变为 `[]`。
