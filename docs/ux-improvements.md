# 日常练习与教学体验优化

2026-10-08。范围：中国站、Go、Pi 原生终端和对话。

## 第一步：日常操作（已实现）

- 首次 `/leet` 自动建立默认练习库，匿名打开 Two Sum；引导默认轻度，可随时调整。
- 登录延后到运行/提交；隐藏凭据输入、复制说明、打开官网、验证后继续原操作。
- `/leet doctor` 显示运行环境、实际加载来源、后端、数据目录及账户状态。
- 运行时保留工作台，允许读题和编辑；结果不抢焦点，旧版本结果明确标记。
- 结果优先展示诊断与逐例输入/输出；记录编号等保留在详情。
- 限流提供冷却反馈，不自动重发；pending 查询恢复；unknown 指向平台记录；保存冲突支持另存草稿。
- F5 可发现所有快捷键。

## 第二步：教学连续性（已实现）

- 所有档位首次进入先显示工作台；F6 明确开始或继续带练。切换档位不启动对话；自主档保持安静；轻度档在有新结果时提供观察。
- 事件按练习与结果去重，重新查询相同结果不重复发言。
- 快捷求助类型与自由输入共存，帮助深度不改变主动程度；上下文按问题裁剪。
- 原生 Pi 对话结束显示返回练习入口；保留焦点、光标和最近讨论。
- 每次练习保存帮助请求、实际回复、用户标注的帮助程度及复盘文本，不从 AC 推断掌握程度。

## 验证

普通回归使用临时目录与模拟平台，覆盖未登录读题、连接后原操作只发送一次、连接取消、后台编辑、恢复查询、逐例缺失输出、帮助去重、模型失败、学习记录与旧数据兼容。
真实终端验证匿名首次进入、快捷键帮助、后台运行及求助返回。使用用户已连接账户仅执行必要 Run，不重复正式提交验收。

实际验收与模型服务限制见 [0.2.0 验收记录](integration-status.md#两步体验优化交付020)。

最终检查：TypeScript 类型检查及 56 项自动化测试通过；80×24 / 120×30 组件预览已更新，最小窗口与中文布局有回归覆盖。

## 2026-10-09：页签导航与鼠标（0.2.3）

- 编辑/阅读区 Esc 只聚焦页签栏，不保存、不退出、不停止后台判题。状态显示“页签导航中”。
- 页签栏左右键循环切页并预览，Enter 进入内容；普通输入和 Tab 不进入编辑器。再次 Esc 才保存返回 Pi，关闭后停止本地等待。
- 点击页签直接切换并进入内容区；命中区域使用渲染后的字符单元宽度，支持中文和窄屏短标签，忽略非左键、非页签及帮助面板中的点击。
- F1–F4 始终可直接进入目标页，F5 帮助退出后恢复原焦点层级。Tab / Shift+Tab 缩进保持不变。
- 代码、笔记、光标与阅读位置在切页时保留；保存冲突留在工作台，不丢草稿。

类型检查与 64 项自动化测试通过；新增覆盖两层 Esc、首个 Esc 不落盘、页签输入隔离、原光标恢复、循环切页、帮助焦点恢复、鼠标命中和缩放后边界。

真实 Pi 1.1.0 工具终端使用隔离 demo 练习验证了 SGR 鼠标点击页签、首次 Esc 草稿不落盘、左右切页、Enter 恢复代码焦点。未调用平台判题或模型服务。

## 2026-10-09：可点击原题链接（0.2.4）

根因：页签接入了鼠标事件，但题面 Markdown 链接只做了显示，没有对应的点击动作。点击回归先复现未处理事件，再验证修复。

- 题面底部原题链接独立渲染并注册可见点击区域，按中文单元宽度、分栏、滚动位置和换行后的 URL 行计算，不依赖固定屏幕行号。
- 左键按下捕获事件，释放后的 click 才执行一次动作，避免一次点击启动两次浏览器；双击的第二次 click 忽略。
- 点击或 F7 先保存草稿，使用题目 slug 构造中国站链接，再调用已有系统浏览器入口。返回后保留焦点与阅读/编辑位置；失败显示可复制的 URL。
- 原题 Markdown 文件保持不变；阅读视图避免重复展示已有原题链接。只对平台原题入口增加点击，不把题面中的任意文本当成可执行链接。

真实 Pi 1.1.0 工具终端：SGR 鼠标按下/释放贯通至 `open` 调用，URL 为当前 Two Sum 原题，随后回到工作台。此验收使用浏览器调用记录桩，没有启动用户浏览器、读取账户或发送判题请求。自动回归同时覆盖成功/失败恢复、草稿保存、滚动/缩放/分栏、换行链接与单次触发。

类型检查与 67 项自动化测试全部通过。
