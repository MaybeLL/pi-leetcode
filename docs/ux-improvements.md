# 日常练习与教学体验优化

2026-10-08。范围：中国站、Go、Pi 原生终端和对话。

## 第一步：日常操作（已实现）

- 首次 `/leet` 自动建立默认练习库，匿名打开 Two Sum；引导默认轻度，可随时调整。
- 登录延后到运行/提交；隐藏凭据输入、复制说明、打开官网、验证后继续原操作。
- `/leet doctor` 显示运行环境、实际加载来源、后端、数据目录及账户状态。
- 运行时保留工作台，允许读题和编辑；结果不抢焦点，旧版本结果明确标记。
- 结果优先展示诊断与逐例输入/输出；记录编号等保留在详情。
- 限流提供冷却反馈，不自动重发；pending 查询恢复；unknown 指向平台记录；保存冲突支持另存草稿。
- F5 可发现所有快捷键。

## 第二步：教学连续性（已实现）

- 所有档位首次进入先显示工作台；F6 明确开始或继续带练。切换档位不启动对话；自主档保持安静；轻度档在有新结果时提供观察。
- 事件按练习与结果去重，重新查询相同结果不重复发言。
- 快捷求助类型与自由输入共存，帮助深度不改变主动程度；上下文按问题裁剪。
- 原生 Pi 对话结束显示返回练习入口；保留焦点、光标和最近讨论。
- 每次练习保存帮助请求、实际回复、用户标注的帮助程度及复盘文本，不从 AC 推断掌握程度。

## 验证

普通回归使用临时目录与模拟平台，覆盖未登录读题、连接后原操作只发送一次、连接取消、后台编辑、恢复查询、逐例缺失输出、帮助去重、模型失败、学习记录与旧数据兼容。
真实终端验证匿名首次进入、快捷键帮助、后台运行及求助返回。使用用户已连接账户仅执行必要 Run，不重复正式提交验收。

实际验收与模型服务限制见 [0.2.0 验收记录](integration-status.md#两步体验优化交付020)。

## 2026-10-09：先读题与工作台整理（0.2.1）

用户截图暴露出：带练抢在读题前启动、未聚焦代码仍显示光标、示例显示 Markdown 围栏、底部操作密集且漏出宿主状态。

- `/leet`、重新练习、换题、切换引导均先留在工作台；F6 保存后进入 Pi 对话，按最近讨论继续，不新增模式。
- 保留 Ctrl+H 分类求助、Esc 保存返回和既有结果事件去重；返回后保持原焦点和光标。
- 标题与保存状态分层，宽屏双栏标注题目/solution.go；边框与 ▸ 共同指示焦点。窄屏单栏。
- 底部为状态、当前常用动作、返回/帮助三行；F6 和 F5 始终可见，正式提交等操作在 F5 中可发现。
- 完整占用工作台覆盖层，避免下方出现宿主 token 状态；不更改 Pi 全局页脚。
- 题面代码块保留内容并隐藏围栏，HTML 转换产生的强调空格在阅读视图修正；不改题目文件或代码示例。

验证覆盖 153×51、120×30、80×24、40×16、32×16。回归验证首次带练不请求模型、显式 F6 保存并交接、继续讨论、换题/新尝试不自动开场、切换档位留在工作台、焦点与退出入口、非焦点光标消失和题面渲染。组件预览保存在 docs/images/；示例为 demo，非在线判题。

## 2026-10-09：编辑按键与操作栏（0.2.2）

- F1–F4 统一切页；Tab 交给代码/笔记编辑器，插入 4 空格；Shift+Tab 移除当前行最多 4 个行首空格，不删除代码。只读视图不再使用 Tab 切页。
- 当前页签以反色实心背景、加粗和 ▸ 标记，窄屏使用短标签，四个页签都可见。
- 底部明确标注“状态”和“操作”；判题/错误状态不再混入快捷键。保存、运行、提交、用例、求助、带练、引导、返回、更多始终显示，整项换行；结果页另提供逐例切换、详情和查询。
- 小窗口的内容高度随操作栏变化，保留编辑光标可见，避免长代码末行被裁掉。
